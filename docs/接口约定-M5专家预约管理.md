# M5 专家预约管理接口约定

> 归属：P3 后端 / P5 前端（专家预约工作台）
> 对应需求：专家处理农户预约，接受或拒绝后状态实时回写。

## 1. 农户我的预约

`GET /api/expert/appointment/my`

- 角色：农户
- 查询当前登录农户自己的预约
- 返回 `List<AppointmentVO>`

## 2. 专家预约列表

`GET /api/expert/appointment/expert`

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| status | 否 | `待处理` / `已接受` / `已拒绝` / `已完成` / `已取消`；不传返回全部 |

规则：

- 仅专家可调用
- 专家身份从 JWT 映射到 `t_expert.expert_id`
- 只能看到分配给当前专家的预约
- 返回 `List<AppointmentVO>`

主要字段：

```json
{
  "apptId": 12,
  "farmerId": 3,
  "farmerName": "王建国",
  "expertId": 1,
  "expertName": "赵国强",
  "expertDomain": "种植与植保",
  "apptTime": "2026-10-11 09:00:00",
  "apptTopic": "果园秋施肥现场指导",
  "apptStatus": "待处理",
  "remark": null,
  "createTime": "2026-10-10 15:11:26"
}
```

## 3. 接受或拒绝预约

`POST /api/expert/appointment/{apptId}/handle`

请求体：

```json
{
  "apptStatus": "已接受",
  "remark": "专家已接受预约，请按约定时间联系。"
}
```

拒绝时必须填写原因：

```json
{
  "apptStatus": "已拒绝",
  "remark": "当天已有其他行程，建议改约。"
}
```

规则：

- 仅专家可调用
- 只能处理自己的预约
- 只有 `待处理` 状态可以处理
- 拒绝时 `remark` 必填，最长 200 字
- 成功后真实更新 `t_appointment.appt_status` 和 `t_appointment.remark`
